# Phase 3M — Scoped live periodic-review reporting

Implemented locally together with 3K/3L, 2026-09-12. The existing Angular/PrimeNG AI review operations screen displays periodic overdue count (GEN-95), due-as-of on-time compliance (GEN-96), seven-day due-soon count, completed/superseded history counts and a paginated next-30-day calendar. Annual comprehensive findings use a separate tab and are not silently included in the periodic-review denominator.

The server computes measures over all eligible review records in the current asset/organization/domain/classification scope, independently of the UI list's pagination and the existing 100-risk register cap. Both risk and use-case sample flags are excluded. Superseded reviews are counted separately and excluded from active obligations. Overdue means uncompleted, unsuperseded and due at/before the server's as-of time. On-time compliance equals due reviews completed by their pinned due date divided by all unsuperseded reviews due as of the report, including overdue open reviews. Empty denominator returns null and the UI shows —. This packet offers a cumulative live projection, not persisted monthly reporting or the entire 21-KPI dashboard.

Governance/audit readers require live eligible explicit grants and case scope. Risk Owner operational reports additionally filter by actual risk ownership; task participation/use-case ownership alone cannot broaden this report. Executive dashboard authority receives scope-checked aggregate counts only, with no risk IDs/references, calendar rows or actions. Auditor reads expose no review write authority. Scope and identities are server-resolved; client clock, aggregate or role injection cannot confer access.

The read-only report GET uses a repeatable-read transaction and stable date/id pagination. Measures currently use a selected complete-population Prisma read; large-register SQL aggregation/caching, monthly snapshots, exports and full dashboard drilldowns remain later work. A page size of 1–100 and positive page are enforced. No new scheduler, service provider, database engine or dependency is added.

Verification: real isolated clean/upgrade database and Nest HTTP tests for complete-population counts, actual-owner filtering, executive aggregate-only payload, Auditor mode, no-due/late/on-time/superseded formula cases and invalid page/client-field rejection; API/Angular builds and focused AI/native/workflow regressions. No browser visual acceptance, external dispatch, live synchronization, publication or deployment is claimed.
