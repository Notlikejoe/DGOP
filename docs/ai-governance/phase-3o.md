# Phase 3O — Evidence-backed annual review officer handover

Implemented locally, 2026-09-13, with 3N/3P/3Q. A pending comprehensive annual review can be handed to another active Responsible AI Officer with explicit eligible grants and full visibility of the organization register and every historical snapshot member. An eligible officer can recover a review from an inactive incumbent. Auditor dual-role writes remain denied.

The existing annual-review card offers an eligible receiving-officer selector, justification and existing evidence identifiers. The server independently validates the nominee, source assignment, pending task, evidence and expected handover round. Original officer identity, annual round, source snapshot, native calendar/occurrence/task/case and due date remain unchanged. Each transfer adds an immutable ledger row and updates the same native task assignee atomically with required audit and workflow history. Old recipient-specific task alerts are archived and task escalations resolved; the existing scheduler can reevaluate the reassigned task. No provider dispatch is added.

Completion requires the current ledger officer and expected handover round. A stale original-officer form cannot complete the review. The next annual cycle is assigned to the completing officer. SQL guards derive the current officer from the append-only handover ledger, protect native task provenance and require atomic reassignment. The UI shows transfer justification/evidence history without new generic workflow mutation authority. Nominee discovery is bounded to 100 active eligible candidates; all candidates are scope-checked.

Verification: clean/upgrade real database tests cover audit rollback, ineligible/inactive nominees, inactive-incumbent recovery, concurrent exactly-one handover, unchanged original identity/deadline, ledger/native-task mutation rejection and current-officer completion/next-cycle ownership.
