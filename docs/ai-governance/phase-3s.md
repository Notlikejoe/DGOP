# Phase 3S — Current risk posture and residual matrix

Implemented locally, 2026-09-13, with 3R/3T/3U. The dashboard adds GEN-86 identified count, GEN-87 exact current HIGH/CRITICAL residual count, GEN-88 open lifecycle count, GEN-89 missing assigned owner, GEN-90/91 mean current inherent/residual scores and GEN-92 mean risk-reduction percentage. Open maps to existing DGOP lifecycle states other than closed/cancelled; no new Withdrawn state is fabricated.

Server queries cover the complete eligible identified population, with active assets/AIRS cases, live scope, non-sample risk/use-case flags and actual Risk Owner operational ownership. Parameterized PostgreSQL DISTINCT ON retrieves only the latest inherent and residual calculation per risk. Results older than the newest original/additional reassessment trigger's required inherent round are excluded. A residual must identify the current inherent assessment; historical residuals cannot silently pair with new scores. Missing scores and empty averages are null. Valid negative reduction remains visible, not clamped. These are current calculated posture measures, not an acceptance claim.

The 4×4 matrix counts current paired residual likelihood/impact cells and displays assessed versus unassessed totals, with numeric score captions in addition to color. Governance/Auditor readers can inspect the top ten current residual risks and scoped read-only summaries. Executive payloads have aggregate matrix/counts and no risk IDs/references, top-risk rows or department rows. Risk-owner mode shows its allowed operational measures and no organization-wide matrix.

Verification: real isolated clean/upgrade tests cover source count reconciliation, matrix total plus unassessed equals identified population, top-ten sorting/bounds, actual-owner summaries and executive/Auditor privacy. Deterministic scenarios cover new inherent versus stale residual, active additional-trigger invalidation, valid pairs, missing-score nulls, zero-action completion and negative reduction. API/web builds and focused AI security contracts pass. Nightly/monthly snapshots, caching and concurrency load acceptance remain later work.
