# Phase 3T — Current approved-plan treatment measures

Implemented locally, 2026-09-13, with 3R/3S/3U. The dashboard adds GEN-93 treated-risk ratio, GEN-94 overdue treatment-action count and GEN-97 High/Critical plan completeness, alongside existing GEN-95/96 review measures and a link to review operations. GEN-97's drilldown explicitly shows missing-completed-action gaps, rather than the successful numerator.

A current treatment plan must belong to the latest eligible approved MITIGATE/TRANSFER response tied to the current inherent assessment and have the latest plan decision approved. Actions must be listed in that immutable plan snapshot, non-deleted, non-cancelled and tied to its response/native task. Latest immutable execution progress supplies completion percentage. Verified completion requires 100%, a completion timestamp and the native task completed. Overdue compares the protected Saudi native task due date with server time; no deadline is edited. Per-risk completion is the mean of eligible current actions, 0 when none exist.

GEN-93 counts current approved-plan risks whose eligible actions are all verified complete divided by all current approved-plan risks; no plan denominator returns null. GEN-97 uses current inherent HIGH/CRITICAL risks and counts those with at least one verified current-plan action complete. Current non-sample risk/use-case flags and optional immutable plan/action JSON sample markers are excluded. The existing schema has no dedicated treatment-plan sample column; source import reconciliation must preserve its sample provenance before production migration certification. Operational roles receive no sample toggle or computed-value writes.

Actual Risk Owner measures and drilldowns stay limited to own risk rows. Auditor summaries remain read-only; executive cards use the design audience subset and no action-level details. Required execution evidence remains enforced by the previously implemented immutable progress/service/SQL guards.

Verification: clean/upgrade application tests exercise the real data projection and scoped filtered reads. Known contract scenarios assert verified completion, partial overdue work, 75% mean, cancellation exclusion, stale-response exclusion and immutable sample-plan exclusion. AI security and API/web builds pass. Treatment warning/breach provider delivery, dedicated source sample migration and persisted monthly treatment reporting remain later work.
