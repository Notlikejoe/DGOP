# Phase 3U — Adoption pipeline projections and explicit KPI coverage

Implemented locally, 2026-09-13, with 3R/3S/3T. The governance/Auditor dashboard adds GEN-81 submitted adoption-request count, GEN-82 terminal acceptance rate, GEN-83 triage SLA compliance and GEN-84 return-for-completion rate. Drafts and sample use cases are excluded. An unlinked request has no registered asset classification/domain, so it is excluded when those scope dimensions are restricted; organization restrictions still apply. Linked requests must meet active-asset scope.

GEN-81 counts cases with a submitted intake revision, once per use case, not one per resubmission. The terminal population maps to installed closed/rejected/cancelled/failed states. GEN-82's numerator uses the latest completed native adoption decision's Approved or Approved with Conditions resolution; approved-but-not-terminal cases are excluded. GEN-83 counts completed triage attempts at/before their original pinned five-KSA-business-day native deadline divided by all completed triage attempts. The installed calendar engine supplied that deadline, so reporting does not reapply an alternate calendar. GEN-84 uses distinct completed triage task IDs with an immutable return event over completed triage attempts; multiple returns/resubmissions are attempt-level, not silently mixed with case-level denominators. Empty ratio denominators are null.

All 21 GEN-81..101 definitions are recorded with bilingual name/formula, unit, design frequency, owner and implementation coverage. Nineteen have live computations. GEN-100 assessment-completeness due cohorts and GEN-101 current High/proposed-High Ethics coverage remain explicitly deferred with no fabricated values. Design Daily/Monthly tags are explanatory; this packet is a cumulative current-scope live projection, not scheduled daily/month-close reports or historical cohort reconstruction. UI shows server as-of time and coverage/measurement notes. Executive cards follow the design subset; Risk Owner gets GEN-88/94/95/97 only.
