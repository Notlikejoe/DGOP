## Visibility and operating contract

Source previews contain unresolved organization labels, people and risk content. Reads require live explicit AIRS visibility, a Responsible AI Officer / DMO / Auditor identity and unrestricted organization/domain/classification coverage. Partial-scope actors fail closed before source loading or saved content access. Officer proposal/disposition uses `refdata.propose.ai`; independent DMO preparation review requires `airs.library.import` and `refdata.publish`. Auditor and generic executive roles cannot write. JWT role claims do not confer authority.

`AI_MIGRATION_SOURCE_DIR` is an operator-controlled fixed local directory. Default: repository `storage/ai-sources`, stable from the API source or compiled module path. It must contain the two manifest-named files with their exact retained digests. Copies are ignored local storage; filenames/hashes are committed, workbook contents are not. No request can provide a filesystem path, remote URL, raw report, score, load mode or production-ready flag. Source files are read only and never recalculated. XML numeric text accompanies typed cached numbers; checksum arithmetic uses exact decimal strings to survive Prisma/PostgreSQL JSON persistence.

Preparation acceptance records review of withheld candidates only. It does not close a migration phase, certify target zero-diff, create an approved AI/AIR/ACT history, publish AIRL/control records, sign off the AI-001..AI-020 pilot or enable production load. There is no target promotion endpoint. Existing R_IMPD eight-versus-seven named-range reconciliation, reviewed cadence and regulatory reference publication gates remain intact.
