## Demonstration walkthrough / دليل العرض

1. Sign in as qa.admin and open the workspace tools. Follow Finance invoice/supplier and HR employee/payroll examples through assets, ownership, quality, privacy, access and reporting. / سجّل الدخول بحساب المسؤول واستعرض أمثلة المالية والموارد البشرية عبر الأدوات المترابطة.
2. Sign in as the Finance and HR owners. Confirm that records stay in their respective scopes and that AI-free profiles do not show AI tools. / تحقق من فصل نطاق المالية والموارد البشرية وإخفاء أدوات الذكاء الاصطناعي للحسابات غير المصرح لها.
3. Use the AI officer and independent specialists to inspect the three completed journeys and the pending review stages. Open risks, treatment actions, review history, dashboard snapshots and source preparation. / استعرض الرحلات المكتملة والمراجعات المعلقة والمخاطر والمعالجات والتقارير وإعداد المصادر بالحسابات المختصة.
4. Compare pending work with completed native history. Keep synthetic evidence labels visible. / قارن العمل المعلق بالسجل المكتمل مع إبقاء وسم الأدلة التجريبية واضحًا.
5. Use the private account guide for credentials. / استخدم دليل الحسابات الخاص لبيانات الدخول.

## Existing workstation commands

Use the pinned Node 24 runtime with the tools under tools/local-preview. The tools are deliberately bound to the isolated 4208 profile and existing checkpoint; they reject other databases. Do not run a destructive seed.

- Resume examples serially: population-core.cjs, population-operations.cjs, population-ai.cjs, population-complete-registers.cjs.
- Verify database coverage: population-acceptance.cjs.
- Start/check/stop the existing preview: population-runtime.cjs start; population-acceptance.cjs; population-runtime.cjs stop. Start does not migrate, install or change passwords.
- Check discovery without duplicates: population-replay.cjs. For the explicit interruption exercise only, set DGOP_TEST_INTERRUPT=1 once, expect incomplete, clear it and resume.
- Backups and private configuration remain outside Git in the local preview state. Restoring them requires the guarded existing database workflow, not a Git pull.
